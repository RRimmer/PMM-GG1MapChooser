# PMM_GG1MapChooser — changelog

## 0.0.2 — 2026-10-07

### Новое: панель голосования за следующую карту
- Голосование GG1 в конце карты (`GlobalWASDMenu` без заголовка) рисуется своей панорамой `pmm_mapvote.xml`, а не обычным меню.
  Подсчёт голосов, `!revote`, продление и смена карты остаются в GG1.
- В каждой строке: номер, картинка карты, название, метка (Badge), полоса голосов, счётчик и «ТВОЙ ГОЛОС».
  Вверху таймер с полосой времени, внизу подсказка и «N / M голосов».
- `Vote.VoteInput`:
  - `Panorama` — у игрока курсор, голос кликом. После голоса курсор пропадает, а панель остаётся и показывает, как идёт голосование.
    Кнопка «×» убирает курсор, голосовать можно через чат.
  - `Chat` — панель без курсора, голос через `!1 … !N`. Подходит для Surf, KZ и других режимов.
- `!1 … !N` (и `/1 … /N`) работают в обоих режимах (`Vote.ChatNumbers`). Сообщение в чат не выводится.
- `Vote.Position`: `Left` / `Center` / `Right` (по умолчанию `Right`).
- Итог голосования (`Vote.ResultStyle`):
  - `Check` — галочка на победившей строке на `CheckSeconds` секунд, потом панель закрывается.
  - `NextMapCard` — отдельная карточка с картинкой, названием и галочкой на `ResultSeconds` секунд.
- Конфиг карт: `Maps` (Title, Image, Badge), `Badges` (имя → цвет), `Specials` (строки «Продлить» и «Не голосую»), `Texts` (все надписи).
  - `Image: "builtin"` или пусто — скриншот карты из клиента CS2 (официальные карты). Остальные карты получают заглушку.
  - `Image: "maps/name.png"` — своя картинка в клиентском аддоне.
- Плагин при загрузке записывает `pmm_mapvote_maps.css` (картинки и цвета меток) рядом с DLL. Команда `css_pmm_gg1 css` перезаписывает его.

### Новое: freeze time на раунд голосования
- `Vote.FreezeTimeVote`: в `round_prestart` плагин спрашивает GG1 (`CheckMaxRounds`), начнётся ли голосование в этом раунде.
  Если да, `mp_freezetime` поднимается до `VotingTime + TriggerVoteAtRoundStartSecondsFromStart + FreezeTimeExtra`.
- После голосования или в конце freeze time старое значение возвращается. Оно сохраняется в `freezetime.restore`.
  Если сервер упадёт посреди голосования, значение восстановится при следующем запуске (`FreezeTimeFallback`, если файл не прочитать).
- `Vote.ExtendFreezeDirect`: если голосование всё же началось при коротком freeze time, конец freeze сдвигается через game rules.
- Голосование по RTV и по времени (`TimeLimit`) посреди раунда идёт без заморозки, только панель.

### Прочее
- `css_pmm_gg1` показывает состояние голосования, слой и сохранённый freeze time.
- Версия плагина внутри DLL теперь совпадает с архивом: 0.0.2.
