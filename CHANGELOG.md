# PMM_GG1MapChooser — changelog

## 0.1.0 — 2026-10-20

Нужен **PMM Core 1.2.05** (MenuManagerCS2): режим «Цифры» берёт клавиши и проверку биндов из ядра.
Со старым ядром всё остальное работает, режим «Цифры» просто недоступен.

### Новое: панель номинации (`!nominate`)
- Список карт справа в стиле панели голосования: картинка, название, метка, номер строки.
- 6 карт на странице, до 60 карт (10 страниц). Картинки — скриншоты карт из файлов CS2 (`map_icons/screenshots/360p`, список сверен с `pak01_dir.vpk`), свои карты — через `Maps.*.Image`.
- Метки в строке: «НОМИНИРОВАНА» (уже в списке GG1), «ТВОЯ НОМИНАЦИЯ», «НЕДАВНО ИГРАЛИ» (перерыв GG1, выбрать нельзя). Внизу — «Номинаций: N / MapsInVote».
- Номинирует сам GG1: выбор строки вызывает его обычный обработчик, все проверки и сообщения GG1 остаются.
- Управление по режиму игрока: мышь — клик, ‹ › и ×; WASD — W / S, A / D страница, E выбрать, R закрыть; цифры — 1–6, 8 / 9 страница, 0 закрыть; чат — обычное меню ядра в чате.
- `Nominate.Enabled: false` — номинация остаётся обычным меню.

### Новое: четыре режима голосования, у каждого игрока свой
| Режим | Как голосовать |
|---|---|
| Мышь | курсор, клик по карте |
| WASD | игрок ходит, W / S — выбор, E — голос, R — настройки |
| Цифры | клавиши 1–9 — голос, 0 — настройки (PanoramaDigitMenu / CSGO Menu ядра) |
| Чат | ничем не скован, `!1 … !N` |

Порядок выбора режима:
1. Режим, который игрок сам выбрал в настройках голосования (`!vm`).
2. Иначе `!menu` игрока, если там не стандартная панорама с мышью: WASD-меню → WASD, чат → чат, «Панорама (цифры)» или CSGO Menu → цифры.
3. Иначе `Vote.DefaultMode` из конфига.

«Цифры» включаются только после пройденной проверки клавиш ядра (`HasNumberKeysChecked`). Без неё берётся следующий шаг.

### Новое: настройки режима голосования
- Кнопка с шестерёнкой и текущим режимом в шапке панели голосования и панели номинации. Команда `!vm` (`!votemode`) открывает их в любой момент.
- Пункты: Авто (как в `!menu`), Мышь, WASD, Цифры, Чат. Управление — тем же режимом, что сейчас у игрока.
- Выбор «Цифры» без пройденной проверки запускает проверку клавиш ядра (`OpenNumberKeysCheck`, ядро печатает строку биндов). Пройдена — включаются цифры, нет — режим не меняется.
- Режим в `!menu` при этом не меняется: можно оставить в ядре цифры, а голосовать мышью.
- Выбор хранится в `plugins/PMM_GG1MapChooser/vote_modes.json` (SteamID → режим). «Авто» удаляет запись.
- `Vote.AllowPlayerChoice: false` — кнопки и `!vm` нет, режим только по `!menu` и конфигу.

### Конфиг
- Новые ключи: `Vote.DefaultMode` (`mouse` / `wasd` / `digits` / `chat`), `Vote.AllowPlayerChoice`, `Vote.SettingsCommands`, `Nominate.Enabled`.
- `ForceMenuType` снова действует только на обычные меню GG1 (админ-список карт, голосование да/нет). Понимает `digits` (PanoramaDigitMenu). Если `Vote.DefaultMode` пустой, он берётся из `ForceMenuType`.
- `ConfigVersion` 3.

### Переводы: `lang/ru.json`, `lang/en.json`
- Все надписи панелей и сообщения в чат перенесены из конфига в `plugins/PMM_GG1MapChooser/lang/`. Есть `ru` и `en`, другой язык — новый файл с теми же ключами.
- Каждый игрок видит панели на своём языке (`!lang` CounterStrikeSharp), в том числе при общем голосовании.
- Из конфига удалены `Texts`, `DefaultTitle` и `Specials.*.Title`. Строки «Продлить» и «Не голосую» — ключи `vote.extend` и `vote.novote`, заголовок обычных меню GG1 — `menu.title`. Старые строки в конфиге ни на что не влияют, их можно удалить.

### Клиентский аддон
- `pmm_mapvote.xml` переписан генератором `tools/gen_layout.py`: три панели (`mv-root`, `nm-root`, `st-root`), кнопка режима, 60 строк номинации, 5 строк настроек, отдельные подписи для «Продлить» / «Не голосую» (текст у каждого игрока свой).
- `pmm_mapvote.css`: кнопка режима, режим цифр, номинация, настройки. Иконки только из игры (`settings`, `mouse_left`, `move_keychain`, `key`, `random_map`, `chatwheel_requestplan`).
- **Аддон нужно пересобрать.**

### Прочее
- Код разделён: `Hud.cs` (одна сущность HUD на три панели), `Players.cs` (режимы, ввод, настройки), `MapVote.cs`, `Nominate.cs`.
- После рестарта раунда все три панели восстанавливаются сами.
- `css_pmm_gg1` показывает режим голосования и фокус каждого игрока.

## 0.0.3 — 2026-10-16

### Новое: три режима голосования за карту
Режим выбирается **для каждого игрока** по тому же правилу, что и обычные меню GG1:
`ForceMenuType` в конфиге, а если он пустой — то, что игрок выбрал в `!menu`.

| Режим | `ForceMenuType` | Как голосовать |
|---|---|---|
| Мышь | `mouse` / `PanoramaMenu` | Курсор, голос кликом. Кнопка «×» убирает курсор. |
| Чат | `chat` / `ChatMenu` (и `console`) | Без курсора, игрок ничем не скован. Голос `!1 … !N`. |
| WASD | `wasd` / `PanoramaWasdMenu` (и `center`, `metamod`, `csgo`) | **Новое.** Игрок может ходить. W / S двигают выделение (по кругу), E голосует. |

- `!1 … !N` (и `/1 … /N`) работают во всех режимах (`Vote.ChatNumbers`).
- Если игрок сменит `!menu` во время голосования, режим панели сменится сразу.
- Подсказка внизу панели — своя у каждого игрока. Новый текст `Texts.HintWasd`.
- Клавиши, зажатые в момент открытия панели (например, W на бегу), выделение не двигают.

### ForceMenuType
- Принимает короткие имена: `wasd`, `mouse`, `chat`, `console`, `center`, `metamod`, `csgo`. Полные имена (`PanoramaWasdMenu` и т.п.) тоже работают. Регистр, пробелы, `_` и `-` не важны.
- Раньше неизвестное значение (например, `"wasd"`) молча игнорировалось. Теперь в логе: `ForceMenuType: <тип>` или предупреждение со списком допустимых значений.
- Теперь задаёт и режим панели голосования.

### Удалено
- `Vote.VoteInput`. Режим голосования задаёт `ForceMenuType`. Строку в старом конфиге можно оставить, она ни на что не влияет.

### Клиентский аддон
- `pmm_mapvote.xml`: три подсказки (`mv_hint_click` / `mv_hint_chat` / `mv_hint_wasd`) вместо одной, у `mv-root` больше нет класса `mode-click` по умолчанию.
- `pmm_mapvote.css`: подсветка выделенной строки `.mv-row.is-cur`, показ подсказки по классу режима, «×» скрыт в режимах чат и WASD.
- **Аддон нужно пересобрать.** Со старым аддоном голосование работает, но не видно выделения в WASD и подсказки.

### Прочее
- Если ядро MenuManager не знает `GetSelectedMenu`, режим берётся через `GetMenuType` (WASD-панорама тогда определяется как мышь).

## 0.0.2 — 2026-10-07

### Новое: панель голосования за следующую карту
- Голосование GG1 в конце карты (`GlobalWASDMenu` без заголовка) рисуется своей панорамой `pmm_mapvote.xml`, а не обычным меню.
  Подсчёт голосов, `!revote`, продление и смена карты остаются в GG1.
- В каждой строке: номер, картинка карты, название, метка (Badge), полоса голосов, счётчик и «ТВОЙ ГОЛОС».
  Вверху таймер с полосой времени, внизу подсказка и «N / M голосов».
- `Vote.VoteInput`:
  - `Panorama` — у игрока курсор, голос кликом. После голоса курсор пропадает, а панель остаётся и показывает, как идёт голосование.
    Кнопка «×» убирает курсор, голосовать можно через чат.
  - `Chat` — панель без курсора, голос через `!1 … !N`. Подходит для Surf, KZ и других режимов.
- `!1 … !N` (и `/1 … /N`) работают в обоих режимах (`Vote.ChatNumbers`). Сообщение в чат не выводится.
- `Vote.Position`: `Left` / `Center` / `Right` (по умолчанию `Right`).
- Итог голосования (`Vote.ResultStyle`):
  - `Check` — галочка на победившей строке на `CheckSeconds` секунд, потом панель закрывается.
  - `NextMapCard` — отдельная карточка с картинкой, названием и галочкой на `ResultSeconds` секунд.
- Конфиг карт: `Maps` (Title, Image, Badge), `Badges` (имя → цвет), `Specials` (строки «Продлить» и «Не голосую»), `Texts` (все надписи; с 0.1.0 — в `lang/`).
  - `Image: "builtin"` или пусто — скриншот карты из клиента CS2 (официальные карты). Остальные карты получают заглушку.
  - `Image: "maps/name.png"` — своя картинка в клиентском аддоне.
- Плагин при загрузке записывает `pmm_mapvote_maps.css` (картинки и цвета меток) рядом с DLL. Команда `css_pmm_gg1 css` перезаписывает его.

### Новое: freeze time на раунд голосования
- `Vote.FreezeTimeVote`: в `round_prestart` плагин спрашивает GG1 (`CheckMaxRounds`), начнётся ли голосование в этом раунде.
  Если да, `mp_freezetime` поднимается до `VotingTime + TriggerVoteAtRoundStartSecondsFromStart + FreezeTimeExtra`.
- После голосования или в конце freeze time старое значение возвращается. Оно сохраняется в `freezetime.restore`.
  Если сервер упадёт посреди голосования, значение восстановится при следующем запуске (`FreezeTimeFallback`, если файл не прочитать).
- `Vote.ExtendFreezeDirect`: если голосование всё же началось при коротком freeze time, конец freeze сдвигается через game rules.
- Голосование по RTV и по времени (`TimeLimit`) посреди раунда идёт без заморозки, только панель.

### Прочее
- `css_pmm_gg1` показывает состояние голосования, слой и сохранённый freeze time.
- Версия плагина внутри DLL теперь совпадает с архивом: 0.0.2.
